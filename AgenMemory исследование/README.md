# AgenMemory исследование

Исследование долговременной памяти автономного AI-агента: как она устроена, когда она начнёт мешать работе и как её организовать иначе.

Объект — агент на ZCode (модель GLM), который работает с инженером над задачами 1С-разработки, CI и инфраструктуры. Снимок от 07.10.2026.

## Как устроена память агента

Пять слоёв, разложенных по стоимости доступа:

| Слой | Что хранит | Как попадает в контекст |
|---|---|---|
| 1. Автопамять (индекс `MEMORY.md` + файлы) | рабочие наблюдения агента | индекс грузится целиком в каждый сеанс, файлы — по требованию |
| 2. memory-mcp | проверенный канон проекта (`checked=true`), общий для нескольких агентов | поиск BM25 + семантика по запросу |
| 3. Викинг ([OpenViking](https://github.com/volcengine/OpenViking)) | долгосрочный опыт и вики владельца | хук подмешивает топ-3 на каждый промпт ≥ 40 символов |
| 4. Шаблоны 1С | библиотека шаблонов кода | по запросу |
| 5. Корпоративный RAG | регламентированные знания по 1С:ЗУП | по запросу, доступен только из корпоративного сегмента |

Правила работы: всё из памяти — гипотеза, пока не подтверждено инструментом; секреты — только ссылкой на защищённое хранилище; опровергнутое удаляется в тот же день. Состояние всех слоёв на старте сессии показывает хук с таймингами.

Подробно — интерактивная карта [`agent/Память-ZCode-структура.html`](agent/Память-ZCode-структура.html).

## Главные выводы

1. **Коллапс будет мягким:** память не переполнит диск, а съест окно контекста, начнёт уверенно врать устаревшими фактами и подмешивать шум. При текущем темпе индекс займёт ~46% окна к апрелю 2027 и ~88% к октябрю 2027.
2. **Без TTL через год ~82% фактов о состояниях систем будут неверны** (при полураспаде факта 45 дней).
3. **Поиск масштабируется, индекс — нет:** шум поиска растёт как √(ln N), стоимость индекса — линейно. Порог 0,6 уже ниже уровня шума; 0,8 держит до ~14 000 чанков.
4. **Хранить указатели, а не значения:** «где проверить режим AI review», а не «AI review ручной».
5. **Один канон фактов, битемпоральные поля, сверка на записи, экзамен памяти** — эволюция текущей схемы, а не замена.
