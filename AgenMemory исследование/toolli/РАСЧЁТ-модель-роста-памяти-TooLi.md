1. Записывай число файлов раз в неделю.
2. Через 4 недели подгони b по методу наименьших квадратов в координатах ln N — ln t.
3. Если b > 0,9 — рост линейный, действуй по худшему сценарию.

## 4. Протухание volatile-фактов

### 4.1 Модель

Приток записей постоянный. Факт остаётся верным с вероятностью 2^(−τ/h), τ — возраст, h — период полураспада.
Доля верных фактов через T дней:

V(T) = (h / (T · ln 2)) · (1 − 2^(−T/h))

Доля неверных = 1 − V(T).

### 4.2 Результат

| h | T = 90 дней | T = 180 | T = 365 |
|---|---|---|---|
| 30 дней | 58% неверны | 76% | 88% |
| 45 дней | 46% | 66% | 82% |
| 60 дней | 38% | 58% | 77% |
| 90 дней | 28% | 46% | 67% |

### 4.3 Вывод

Агент оценил «≥30% протухших» для всей памяти. Это согласуется с моделью, если volatile-фактов около 40% корпуса.
Без TTL через год 4 из 5 фактов о состояниях (серверы, CI, доступы, режимы) будут неверны.
TTL 30–60 дней из устава агента — математическая необходимость, не перестраховка.

## 5. Окупаемость строки индекса

### 5.1 Формула

Строка индекса грузится в каждый сеанс. Она окупается, если её используют хотя бы раз в N дней:

N = S / (L × s)

- S — токены, сэкономленные одним попаданием;
- L — токены строки;
- s — сеансов в день.

### 5.2 Результат

| L, токенов | S = 5k, s = 5 | S = 5k, s = 15 | S = 20k, s = 5 | S = 20k, s = 15 |
|---|---|---|---|---|
| 60 | 16,7 дн. | 5,6 | 66,7 | 22,2 |
| 130 | 7,7 | 2,6 | 30,8 | 10,3 |
| 250 | 4,0 | 1,3 | 16,0 | 5,3 |

### 5.3 Вывод

Типичная строка (130 токенов, 10 сеансов/день) окупается при использовании раз в 4–15 дней.
Строки-«простыни» по 250 токенов — раз в 1–5 дней.
Правило архивации: **строка без использования 30 дней уходит в архив.** Это мягче точки безубыточности, полезное не потеряется.

## 6. Шум поиска

### 6.1 Модель

Скоры нерелевантных чанков ≈ нормальное распределение (μ, σ). Ожидаемый максимум из N значений растёт как закон экстремальных значений:

max ≈ μ + σ · √(2 · ln N)

Параметры для bge-m3: μ = 0,45, σ = 0,08. Это оценка TooLi, не замер.

### 6.2 Результат

| Чанков | Лучший скор нерелевантного |
|---|---|
| 100 | 0,69 |
| 367 (сейчас) | 0,72 |
| 1 000 | 0,75 |
| 5 000 | 0,78 |
| 20 000 | 0,81 |

Модель предсказывает 0,72 при 367 чанках. Агент наблюдал ложное попадание 0,74. Совпадение хорошее, но это одно наблюдение, не доказательство.

### 6.3 Выводы

1. **Порог 0,6 ниже уровня шума.** Почти каждый промпт получает мусор в топ-3. Сильнее всего — когда релевантного документа нет вообще.
2. **Поиск масштабируется хорошо, индекс — плохо.** Шум поиска растёт как √ln N, стоимость индекса — линейно по N. Знание переносить из индекса в поиск, не наоборот.

4. μ и σ для bge-m3 — оценка. Проверка: 100 случайных пар (промпт, нерелевантный чанк) → среднее и стандартное отклонение скоров.

1. **Подними порог хука Викинга до 0,80.** Самая дешёвая мера с самым быстрым эффектом.
2. **Откалибруй порог на данных.**

   3. Выбери порог с точностью не ниже 80%.
   4. Повторяй калибровку при росте корпуса в 3 раза.
3. **Добавь правило отказа.** Если разрыв скоров между топ-1 и топ-3 меньше 0,03 — не подмешивай ничего. Плоское распределение значит, что релевантного документа нет.
4. **Зафиксируй бюджет индекса: 15 тыс. токенов** (≈ 250 строк по 60 токенов). Бюджет не зависит от объёма истории. При переполнении самая холодная строка уходит в архив.
5. **Логируй чтения файлов по строкам индекса.** Без лога правило «30 дней без использования» не работает.
6. **Введи TTL 45 дней для volatile-фактов.** Поле `verified: <дата>`. Просроченный факт помечается «было верно на <дата>».
7. **Измеряй рост раз в неделю.** Через 4 недели перезапусти модель и выбери сценарий из раздела 3.

## Приложение A. Код модели (Python 3, без зависимостей)

Копия: `memory_forecast_2027.py` (в этой папке).

```python
import math
W=200_000; F0=69; T0=2.5
TOK_PER_FILE=11_000/F0
weeks={'01.2027':12.5,'04.2027':25.5,'10.2027':51.5}
def lin(r): return lambda t: F0+r*t
def powr(b):
    a=F0/T0**b; return lambda t: a*(T0+t)**b
sc={'agent 20/wk':lin(20),'actual 27.6/wk':lin(F0/T0),'power b=0.7':powr(0.7),'power b=0.5':powr(0.5)}
for n,f in sc.items():
    print(n, [(round(f(t)), round(f(t)*TOK_PER_FILE/1000), f'{f(t)*TOK_PER_FILE/W:.0%}') for t in weeks.values()])
    print('  weeks to 15/25/40%:', [next((t for t in range(600) if f(t)*TOK_PER_FILE>=p*W),None) for p in (.15,.25,.40)])
for h in (30,45,60,90):
    print('h',h,[f'{1-(h/(T*math.log(2)))*(1-2**(-T/h)):.0%}' for T in (90,180,365)])
for L in (60,130,250):
    print('L',L,[round(S/(L*s),1) for S in (5000,20000) for s in (5,15)])
mu,sg=0.45,0.08
print([(N, round(mu+sg*math.sqrt(2*math.log(N)),2)) for N in (100,367,1000,5000,20000)])
```
