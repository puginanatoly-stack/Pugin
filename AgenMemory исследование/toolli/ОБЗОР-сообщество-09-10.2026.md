## Выводы для исследуемой системы

1. «Указатели вместо значений» и битемпоральность — в мейнстриме: инвалидация с учётом происхождения — отдельное направление.
2. Правило «память — гипотеза до проверки» подтверждено (Environment-Probing Curation).
3. Новое: даже верная память вредит → инъекция хука Викинга должна быть селективной, не только по порогу.
4. Новое: just-in-time память против заранее собранного индекса → аргумент за малый индекс-указатель.
5. Новое для общей командной памяти (шлюз MCP с памятью): нужна авторизация по аудитории и учёт происхождения.
6. Экзамен памяти можно автоматизировать (MemDream).
