# Ситуация (контекст)

2001 год, проект в финтех-направлении банка. Анатолий работал инженером.
Задача — оценка информационной безопасности: требовалось настроить
инфраструктуру строго по регламенту (стандартные регламентированные
ИТ-практики).

# Мои мысли (chain of thought)

[не надиктовано]

# Принципы и паттерны

Сверх обязательного регламента — поиск и применение недокументированных
возможностей для усиления системы за пределами формальных требований
(H005, H007). Минимальные ресурсные затраты, непропорционально большой
эффект (H001).

# Принятое решение и действие

Нашёл недокументированные возможности Windows, которые дополнительно
(сверх выполненного регламента) повышают изоляцию информационной системы
примерно на 300%, при минимальных ресурсных затратах.

# Итог и ретроспектива

Успех. Вывод самого Анатолия: изучение недокументированных возможностей —
практика, которую стоит делать больше и лучше (см. H007).
