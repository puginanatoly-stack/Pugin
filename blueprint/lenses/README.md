# Lenses — Слой 3: ментальные фильтры

Каждый файл — набор вопросов, которые Анатолий задаёт себе перед определённым типом решения. Агент, обученный на этом слепке, должен сначала применить подходящую линзу к входящим данным и только потом генерировать ответ.

## Формат

```markdown
# <Название линзы>

Когда я <тип ситуации>, я задаю себе:
1. Вопрос 1
2. Вопрос 2
3. ...
```

Шаблон для копирования: [`_template.md`](_template.md).

**Важно:** линзы пишет только Анатолий — TooLi не выдумывает вопросы за него.
